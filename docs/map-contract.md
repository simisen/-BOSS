# 地图契约（灰盒版）

本文是地图与 Core 之间的**坐标契约**。改地图必须同步本文与 `ModConstants`。

## 1. 基本参数

| 项 | 值 |
|---|---|
| 地图资产名 | `Maps/LeliaFarm_Manor` |
| 源文件 | `content/[CP] LeliaFarm/maps/manor_farm.tmx` |
| 生成脚本 | `scripts/generate-greybox-map.ps1` |
| 尺寸 | **64 × 40 格**，图块 16×16 px → 世界 1024 × 640 px |
| 图层 | `Back` / `Buildings` / `Paths` / `Front`（四层都是 64×40 的 CSV） |
| 地图属性 | `Outdoors = T`；`LeliaFarmMap = 1`（本模组自用标记，游戏忽略） |
| 图块贴图 | 内容资产 `Maps/lelia_farm_tiles`（由内容包 `Load` 提供），64×16，4 格 |

### 图块编号

TMX `firstgid = 1`，CSV 里写的是 **gid**：

| gid | 含义 | 图块属性 | 用途 |
|---|---|---|---|
| 0 | 空 | — | Buildings / Front 层 |
| 2 | 草地 | — | Back 层默认地面（不可耕种） |
| 3 | 土壤 | **`Type=Dirt`** | 作物区（可翻地） |
| 4 | 石板路 | `Type=Stone` | 道路、交付点 |

`Type=Dirt` 是**能不能翻地**的关键：原版锄头逻辑读 Back 层图块的该属性。
灰盒把属性写在自己的图块上，因此不依赖原版图块索引。测试 `Map_SoilTileCarriesDirtProperty` 会守住这一点。

## 2. 区域与坐标（权威值）

| 区域 | X 范围 | Y 范围 | 说明 |
|---|---|---|---|
| 作物区（土壤） | 30 – 45 | 12 – 22 | 16×11 = 176 格可耕种 |
| 主路（水平） | 8 – 56 | 18 | 石板路，交付点在这条路上 |
| 竖路 | 22 | 6 – 18 | 连接北侧（农舍方向）与主路 |
| 林地（预留） | 4 – 26 | 26 – 36 | 灰盒只留空区，供后续种树/采集 |
| 池塘（预留） | 50 – 58 | 26 – 34 | 灰盒只留空区，未做水面 tile 属性 |

**交付入口：`(42, 18)`** —— 对应 `ModConstants.DeliveryTileX / DeliveryTileY`。
交互半径 1.6 格（`DeliveryService` 的 `DeliveryPoint.RadiusTiles`）。
站在这块路面上、手持符合配置的农产品、按交互键即可交付。

## 3. 保护区域（开发命令不得覆盖）

`lelia_dev_setup` 的硬约束（代码在 `Services/DevCommands.cs`）：

- **不移动、不删除**任何既有 `Building` 与 `terrainFeatures`；
- 建筑：同类型已存在则跳过；目标地块被占用则跳过该部分并报告；
- 作物：只往"没有 terrainFeature 且 `isTileOpenBesidesTerrainFeatures` 为真"的地块种；
- 动物：按类型计数，达到目标数量即跳过；
- 目标坐标：鸡舍 `(24,10)`、畜舍 `(34,10)`（由交付点偏移推出），作物区复用上表。

**保护区域**（未来放建筑/装饰时不得占用）：
- 主路 `y=18`、`x∈[8,56]` 与竖路 `x=22`、`y∈[6,18]`：保持通行；
- 交付点 `(42,18)` 及其周围 2 格：不得放置阻挡物；
- 作物区 `x∈[30,45], y∈[12,22]`：不放建筑。

## 4. 季节

灰盒地图只用一张非季节贴图，因此**四季外观相同**，不存在"某季节缺图"的崩溃路径。
正式素材如果要做季节差异，建议用 Content Patcher 的 `Season` token 切换贴图资产，
而不是复制四份地图。

## 6. 未验证项与已知缺口（必须如实记录）

1. **地图出口（`Warp`）未编写。**
   原版农场靠地图的 `Warp` 属性连到 `Backwoods`/`BusStop`。
   本项目没有写 `Warp`，因为原版 `Farm.tmx` 是 LZX 压缩的 `.xnb`，无法在不进游戏的情况下取出**准确的**目标坐标；
   随便填坐标会造成"看起来能用、实际走错/卡住"，比缺失更糟。
   **补法**：在游戏内用 Tiled + 一个 tbin→tmx 导出流程（或参考同版本自定义农场 mod 的 `Warp` 值）得到真值后，
   写进本文件 §2 并同步 `manor_farm.tmx` 的 `<properties>`。

2. **农舍/出货箱/邮箱的自动放置未验证。**
   原版由 `Farm.AddDefaultBuildings` 处理，自定义农场类型下是否自动摆放尚未实测。
   若实测发现缺失，补法是内容包 `EditMap` 或 Core 在 `SaveLoaded` 时补放（需另做幂等检查）。

3. **TMX 的 `<image source="Maps/lelia_farm_tiles">` 解析方式未验证。**
   星露谷运行时把图块的 `ImageSource` 当**内容资产名**去内容管理器加载；
   本包已用 CP `Load` 注册同名纹理资产。如果实测发现 TMX 加载器把它当相对文件路径解析，
   症状是进农场黑图/丢图块，修法是改用 `.tbin` 地图（`TileSheet.ImageSource` 可控）或把贴图放到解析器期望的位置。

4. **池塘没有水面属性**，目前只是"留空的草地"。放水需要水体图块属性与碰撞，属于后续工作。

以上四条都已写进 `docs/CHANGELOG.md` 的"已知问题"，不做无根据的"已实现"声明。
